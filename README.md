Entry for the make.fun **One-Line Laugh-Off** bounty: a single funny line, written by a pure-stdlib Python program (`main.py`) that outputs exactly one joke to `/output/entry.txt`.

The joke: a smart fridge snitches on its owner's midnight snacks to the doctor — and the owner discovers betrayal can be literally cold. A mundane appliance, an absurd escalation, and a double-meaning punchline in 100 characters, with nothing left to trim.
